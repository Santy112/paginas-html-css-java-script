Proyecto web desarrollado como trabajo académico para la facultad.

PixelForge es un sitio web institucional y de e-commerce ficticio, diseñado para una marca de soluciones digitales y componentes de hardware, con un enfoque en estética moderna y funcionalidad técnica.

📝 Descripción del proyecto

El sitio representa una plataforma integral de hardware y servicios digitales e incluye:

  Página de inicio: Presentación de la identidad de PixelForge y servicios principales.
  Tienda Online: Catálogo de productos con sistema de selección.
  Carrito de compras: Funcionalidad para gestionar productos seleccionados.
  Página de contacto: Formulario de validación para consultas de usuarios.
  Diseño Responsive: Interfaz totalmente adaptada a dispositivos móviles.

El objetivo del proyecto es aplicar y demostrar conocimientos avanzados de HTML, CSS y JavaScript en un entorno de sitio web funcional, bien estructurado y con navegación fluida.

🛠️ Tecnologías utilizadas

HTML5 – Estructura semántica del sitio.
CSS – Diseño visual, maquetación (Flexbox/Grid) y animaciones.
JavaScript – Lógica del carrito, interactividad y validaciones.
LocalStorage – Persistencia de los datos del carrito de compras.
Google Fonts – Integración de tipografías modernas para legibilidad.

📂 Estructura del proyecto

  `/css`: Archivos de estilos y diseño responsive.
  `/img`: Recursos visuales, logos y assets de productos.
  `/js`: Scripts para la lógica del e-commerce y componentes dinámicos.
  `index.html`: Página principal y acceso al ecosistema del sitio.

📖 Documentación

El proyecto incluye una base técnica donde se detalla:

1. La arquitectura del marcado HTML.
2. El uso de CSS para lograr una experiencia de usuario (UX) consistente.
3. La lógica de JavaScript aplicada al carrito de compras y la gestión de eventos.

Esta documentación fue realizada exclusivamente con fines académicos para facilitar la evaluación del código por parte de la cátedra.
